# PDF Master Pro

Mobile-friendly Flask starter for PDF, Word and Excel conversions.

## Run locally
Install Python 3.12, then run `python -m pip install -r requirements.txt` and `python app.py`. Open http://127.0.0.1:5000.

## Features planned/included in starter
PDF to Word/Excel, Word/Excel to PDF, PDF rotate/merge/extract pages, add text and basic existing-text replacement.

This is an MVP, not a full PDF word processor. Conversion fidelity varies; scanned PDFs need OCR. Do not upload confidential documents to a demo deployment.
